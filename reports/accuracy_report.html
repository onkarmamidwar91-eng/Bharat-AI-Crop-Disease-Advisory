✔ Scientific Note on PlantDoc Domain Shift: The performance gap between controlled laboratory data (PlantVillage: 95.53%) and in-the-wild farm photographs (PlantDoc: 17.02% Top-1, 47.81% Top-5, 76.10% binary detection) reflects standard academic findings. Real farm images contain heavy occlusion, soil background, and multi-leaf clutter. The dual-stage pipeline uses binary disease screening (76.1%) followed by Top-5 candidate retrieval into Llama 3.2 via ExecuTorch for conversational disambiguation.
